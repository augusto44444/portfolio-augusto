Editor local de projetos

Abra o arquivo dist/projects.json, edite os dados abaixo e baixe a nova versão. Substitua o arquivo original e publique uma nova versão do site. Este editor funciona no seu computador e não faz parte do site publicado.

Campos por projeto: title, description, contribution, stack, image, imageAlt, gallery, video, appUrl, sourceUrl, access e demoAccounts. Textos têm versões pt, en e es. Use URLs públicas HTTPS para mídia; inclua apenas contas de teste autorizadas para divulgação pública.
